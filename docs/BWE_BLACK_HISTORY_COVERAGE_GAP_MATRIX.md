## Immediate interpretation

- The current library already does useful work as a source gateway and truth-framing page.
- It is still thin on topic-by-topic historical substance.
- The biggest current gaps are East Africa, North Africa beyond the Nile corridor, Black America after emancipation, and evidence-based wealth-exclusion history.
- Workstream 002 should therefore preserve the current resource library and build layered substantive sections on top of it.
